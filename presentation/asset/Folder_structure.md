## 1. 개요

한국교육고용패널 I(KEEP I, KRIVET) 1~13차(2004~2016) 자료 묶음이다. 폴더 구조는 크게 두 덩어리로 나뉜다.

| 구분 | 폴더 | 성격 | 용량 |
|---|---|---|---|
| (A) 1~12차 원자료 | `KEEPI_Data_Codebook_1_to_13/DATA(수능, 직업력, 가중치, 패널조사현황 자료 포함)/` | 차수별·코호트별·포맷별로 **분산**된 raw 원자료 (SAS/SPSS/TXT) | 약 862 MB |
| (B) 13차 무료 공개판 | `KEEPI_Data_Codebook_1_to_13/KEEPⅠ_무료(13차)/` | 1~13차를 통합한 **Balanced Panel**(wide) + 13차 본조사 + 코드북·매칭맵 | 약 51 MB |
| (C) 공통 부속자료 | `LAYOUT/`, `설문지/`, `사용자지침서 및 코드북/` | 레이아웃·설문지·통합 사용자지침서/코드북 PDF | 약 29 MB |

**전체 규모 [확인됨]**: 디렉터리 157개, 파일 238개(`.DS_Store` 제외).
**확장자 분포 [확인됨]**: `.sav` 59, `.txt` 55, `.sas7bdat` 55, `.pdf` 39, `.xlsx` 29, `.hwp` 1.

핵심 결론을 먼저 제시한다.
- **1~12차는 raw 원자료**가 차수×코호트×포맷으로 흩어져 있고(횡적으로 wide, 종적으로 통합 안 됨), 패널 분석을 하려면 사용자가 직접 병합해야 한다.
- **13차 `KEEPⅠ_무료(13차)` 폴더만 "무료 공개판"**으로, 1~13차를 이미 결합한 **Balanced Panel Data(균형패널, wide 포맷)**를 제공한다. 데모에 즉시 쓸 수 있는 형태는 여기뿐이다.
- 따라서 **데모는 (B) 13차 균형패널 xlsx + 코드북/매칭맵을 주력**으로 하고, (A)·(C)는 보조·검증용으로 둘 것을 권고한다.

### 3-1. 1~12차 차수별·코호트별 파일 분포 [확인됨]

SAS·SPSS·TXT 세 포맷은 **완전히 동일한 차수/코호트 구조**를 미러한다(동일 데이터, 포맷만 다름).

| 차수(연도) | 코호트 폴더 수 | 차수당 파일 수(각 포맷) | 비고 |
|---|---|---|---|
| 1차(2004) | 2 (고3·중3) | 10 | 학교·가구·교사·행정가 등 최다 |
| 2차(2005)·3차(2006) | 2 | 7 | |
| 4차(2007) | 2 | 9 | |
| 5차(2008)·6차(2009) | 2 | 2 | 학생 본체만 |
| 7차(2010)~10차(2013) | 3 (고3·중3·보정패널) | 3 | **7차부터 보정패널 코호트 추가** |
| 11차(2014)·12차(2015) | 3 (라벨이 "코호트"로 변경) | 3 | 폴더명 "보정 패널 코호트" |

- **코호트 라벨 변화 [확인됨]**: 1~10차 폴더명은 "고등학교 3학년(생) 코호트 / 중학교 3학년(생) 코호트 / 보정패널", 11~12차는 "고등학교 3학년 코호트 / 중학교 3학년 코호트 / 보정 패널 코호트"로 명칭이 미세하게 다름(공백·생 유무). 자동 병합 시 폴더명 하드코딩 주의.
- **보정패널** = 표본 이탈 보정을 위해 7차(2010) 신규 투입된 추가 표본. SAS 예: `7~10차 보정패널/f8_c_youth.sas7bdat`.

## 4. 포맷 비교 (SAS / SPSS / TXT) 및 읽기 방법

| 포맷 | 확장자 | 라벨·메타 | 현재 환경 읽기 | 장점 | 단점 |
|---|---|---|---|---|---|
| SAS | `.sas7bdat` | 변수 라벨 내장 | `pandas.read_sas()` 또는 `pyreadstat.read_sas7bdat()` | 라벨 보존, 표준 | Stata/R 외 도구에서 일부 인코딩(한글) 깨질 수 있음 [확인필요] |
| SPSS | `.sav` | 변수·값 라벨 내장(가장 풍부) | `pyreadstat.read_sav()` **[확인됨: 1.1.9 정상 작동, 인코딩 기본값]** | 값 라벨까지 보존, 한글 라벨 양호(실측: GENDER/BYSCLASS/NEW_YN 한글 값라벨 완독) | `encoding='utf-8'` 강제 시 오류 → 기본값으로 호출 |
| TXT | `.txt` | 라벨 없음(원시 텍스트) | `LAYOUT/*.xlsx`로 컬럼 위치 지정 후 `pandas.read_fwf`/`read_csv` | 범용·가벼움 | 별도 LAYOUT 필수, 가장 수작업 多 |
| **XLSX(13차)** | `.xlsx` | 헤더=영문 변수명, 라벨은 코드북 별도 | `openpyxl`/`pandas.read_excel()` | **즉시 읽힘, 설치 의존성 최소** | 값 라벨 미내장(코드북 참조 필요), 대용량은 느림 |

**데모 환경 권고 [확인됨, 정정]**: pyreadstat 1.1.9가 정상 작동함이 리더·본 에이전트 재검증으로 확인되었다. 따라서 **데모 1차 소스는 `.SAV`(pyreadstat `read_sav`, 인코딩 기본값)로 격상**한다 — 값 라벨 자동 부착이 정제 단계의 핵심 셀링포인트다. `.SAV` 읽기에 실패하는 경우에만 `.xlsx`로 폴백한다. 1~12차 `.txt`는 LAYOUT 의존도가 높아 데모 부담이 크다.

## 5. 핵심 질문 분석 — "13차는 왜 별도로 분리되어 있는가?"

### 5-1. 가설
1. (H1) 13차 폴더는 KRIVET이 배포하는 **"무료(공개)판"**이며, 일반 사용자가 신청 없이 받을 수 있는 버전이다.
2. (H2) 1~12차는 **차수별 raw 원자료**(병합 전), 13차 폴더는 **1~13차를 결합한 통합 균형패널**(wide, 분석 즉시 사용 가능)을 제공한다.
3. (H3) 13차 폴더는 자체적으로 데이터+코드북+매칭맵+설문지를 모두 갖춘 **자기완결형 배포 단위**다.

### 5-2. 검증 결과 [확인됨]

| 근거 | 관찰된 사실 | 가설 판정 |
|---|---|---|
| 폴더명 | 상위 폴더명이 `KEEPⅠ_무료(13차)` — "무료"가 명시 | **H1 지지** |
| Balanced Panel 차원 | 학력 3,151×671, 직업 3,151×1,001, 기타 3,151×1,060 — wide 포맷, 모든 차수가 컬럼으로 펼쳐짐 | **H2 지지** |
| ID 컬럼 | 세 파일 모두 선두 8개 동일: `BYSID, BYHID, GENDER, BYSCLASS, NEW_YN, 학생기초Data_차수, BYAID, BYTID` → 동일 표본을 ID로 병합 가능한 통합 패널 | **H2 지지** |
| 매칭맵 | `매칭맵.xlsx`에 시트 `1~12차 변수매칭`(391×26)이 있고, 행마다 `12차 변수명 / 1차(일반고) / 1차(전문고) / 2차(대학생) …` 컬럼으로 **차수별 변수명을 한 변수로 통합**한 매핑 제공 | **H2·H3 지지** |
| 1~12차 폴더 | 차수×코호트×포맷으로 흩어진 raw(`by_h_*`, `f8_c_youth` 등) — 통합본 없음 | **H2 지지(대비)** |
| 자기완결성 | 13차 폴더 내부에 Data/설문지/코드북·매칭맵 3종 세트가 모두 존재 | **H3 지지** |

### 5-3. 결론
- **13차가 별도인 이유**: 13차 폴더는 별도 차수 데이터를 담는 칸이 아니라, **KEEP I 전체(1~13차)를 마무리하며 KRIVET이 무료 공개한 "최종 통합판" 패키지**다. 핵심 가치는 ① 차수·코호트로 흩어진 raw를 ID 기준으로 **결합한 균형패널(wide)**, ② 차수별로 다른 변수명을 통일한 **매칭맵**, ③ 통합 코드북이다. 1~12차 원자료는 "재료", 13차 폴더는 "완제품"에 해당한다.
- **반증 여부**: "1~12차=차수 분산 raw, 13차=통합 균형패널"이라는 명제는 **반증되지 않고 모두 확인됨**. 다만 균형패널이 1~13차 전부를 포함하는지(13차 본조사 변수까지 wide에 결합됐는지)는 변수 라벨 단위로 더 확인이 필요하다 → 6장.

> 보충 [확인됨]: 13차 본조사 데이터(3,151×308)의 `COHORT` 컬럼 분포는 `04년 코호트1 중학생 753 / 04 코호트2 전문고 741 / 04 코호트2 일반고 744 / 07 신규 전문고 336 / 07 신규 일반고 136 / 07 신규 조기졸업 83 / 10 보정 4년제 206 / 10 보정 2·3년제 151`로, 본조사와 균형패널이 **동일한 3,150명 균형표본**을 공유함을 보여준다(헤더 1행 제외 시 3,150).
