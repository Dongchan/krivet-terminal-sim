## 1. 검증 개요 및 방법

### 1.1 검증 대상과 절차
4개 에이전트 보고서(폴더구조·데이터·자료설명·방법론)와 적대적 검증 3종(데이터정확성·방법론타당성·요구사항충족)을 종합했다. 리더는 다음을 **직접 파일을 열어 재검증**했다.

| 리더 검증 항목 | 방법 | 결과 |
|---|---|---|
| pyreadstat 작동 여부 | `import pyreadstat`(1.1.9), `.SAV` 값라벨 추출 | **작동함(보고서와 반대)** |
| 균형패널 `.SAV` 한글 라벨 | 학력 `.SAV` 메타 추출 | `GENDER='성별'`, `BYSCLASS` 값라벨 5종 한글 정상 |
| `F11Y04001` 존재 여부 | 균형패널 3종 xlsx 헤더 전수 검색 | **3파일 모두 부재**(`Y04` 접두 0개) |
| 매칭맵 `F11Y08049` 매핑 | 매칭맵 `1~12차 변수매칭` 시트 행 대조 | 5차=`F4Y08060`, 8차=`F7Y08049`(보고서와 다름) |
| 본조사 조사연도 | `AGE`×`COHORT` 재산출 | 04 중3코호트 평균 29.8세 → **2019년 조사** 지지 |
| 매칭맵 가이드 시트 행수 | `데이터 구축 가이드` max_row | **57행**(보고서 44) |
| 전체 규모 | `find` 디렉터리/파일 카운트 | 디렉터리 157·파일 238 일치 |
| 직업력 종단 데이터 | 폴더 실재 확인 | xlsx 1 + LAYOUT + hwp 존재 |
| 대체 취업변수 후보 | 직업파일 헤더 검색 | `BYJ107009`(종사상지위), `BYJ105014/205014`(일자리형태) 실재 |

### 1.2 핵심 판정 요지
- **데이터 사실 기반은 대체로 견고**하다. 표본 n=3,150, 코호트·성별 분포, 임금·SES 기초통계는 리더 재산출에서 모두 일치했다.
- 그러나 **데모 실행을 좌우하는 두 개의 전제가 사실과 다르다**: (1) `pyreadstat` 사용 가능 여부, (2) 이항 취업 성과변수 `F11Y04001`의 존재. 두 가지는 모두 리더가 직접 파일을 열어 확정했다.
- 이 두 가지를 정정하면 데모 설계의 **품질이 오히려 상승**(값라벨 자동 부착이라는 핵심 셀링포인트 복원)하거나, 깨졌을 트랙(이항 모형)을 **실재 변수로 재정의**할 수 있다. 따라서 **반려가 아니라 조건부승인**이 타당하다.

## 2. 보고서별 평가

### 2.1 `Planning/Folder_structure.md` — 평가: 양호(경미한 연도 표기 수정 필요)
- **강점**: 디렉터리 157·파일 238·확장자 분포가 리더 재산출과 정확히 일치. "13차=무료 통합 최종판" 가설을 폴더명·균형패널 차원·매칭맵 3중 근거로 입증한 논리가 명료하다. 데모 주력/보조/제외 파일 권고가 실용적이다.
- **수정 필요**: §3 요약표에서 `01. 본조사 Data`를 "13차(2016) 본조사 단년 데이터"로 표기한 부분이 오해를 부른다. 리더 실측 결과 본조사 `AGE`(04 중3코호트 평균 29.8세, ~1989년생)는 **2019년 조사**와 정합하며, 이는 별도 '청년층 노동시장 이행 추적조사'다. `[검증반영]`

### 2.2 `Planning/Data_exploration.md` — 평가: 우수(단, §0 환경 전제가 치명적 오류)
- **강점**: wide→long reshape 실연(3,150×12 → 28,350×5), 접두사별 변수개수표, 음수 결측코드 처리(첫직업임금 73.6 vs 117.1), "결측≠이탈" 통찰은 데모 설계의 핵심 자산이다. 기초통계 수치는 리더 재산출과 소수점까지 일치.
- **치명적 오류**: §0에서 `pyreadstat`를 "사용 불가(`cannot import name 'TypeAlias'`)"로 단정했다. **리더 실측: pyreadstat 1.1.9가 정상 import되고 `.SAV`를 값라벨·한글까지 완벽히 읽는다.** 이 오류가 4개 보고서 전체로 전파되어, 데모의 핵심 셀링포인트인 '코드북 값라벨 자동 부착'을 불필요하게 포기시켰다. `[리더 실측]`
- **경미 오류(검증반영)**: 직업파일 잔여컬럼 71→73, TXT 고정폭 979→978, 고3 파일 예시에 중3 LAYOUT 350행 인용(고3은 366/369행).

### 2.3 `Planning/Data_description.md` — 평가: 우수(변수 카탈로그 최고 품질, 매칭예시 1건 오류)
- **강점**: 변수 카탈로그(SES·교육·노동·이동성), 결측코드 규약, 코드북-데이터 불일치(`BYH20001` 연속 vs 6구간, `BYH26006`에 8·9값) 적출은 분석 정확성에 직결되는 고품질 산출물이다. 본조사=2019 추적조사로 올바르게 식별.
- **수정 필요**: §3.4 매칭예시 `F11Y08049` 행이 자기불일치. 보고서는 "5차=`F5Y08053`, 8차=`F8Y08049`"로 적었으나 **리더 실측 매칭맵 값은 5차=`F4Y08060`, 8차=`F7Y08049`**다. 이는 보고서 스스로 명시한 (n→n+1차) 규칙(F4=5차, F7=8차)과도 모순된다. §3.4 전 셀을 매칭맵 행과 1:1 재대조해야 한다. `[리더 실측]`
- **경미 오류**: §3.1 가이드 시트 44행→**57행**(리더 실측), §5 본조사 코드북 레이아웃에 `col4=결측값` 누락.

### 2.4 `Planning/Method_exploration.md` — 평가: 우려있음(설계 골격 탁월, 입력변수 2건이 데이터와 불일치)
- **강점**: 10개 설계항목 완비, 검정 9종의 H0·판단기준·3도구 매핑, Mundlak/CRE를 1차 권장 종착으로 둔 논리(시불변 SES→FE 소거 회피)는 본 데이터의 구조를 정확히 반영한 모범 설계다. AI 논문플로우 9단계, between/within 분산분해, 시각화 12종 설계가 요구사항을 충실히 커버한다.
- **우려 1(이항 성과변수 부재)**: 취업 트랙의 메인/강건성 모형 종속변수로 지정한 `F11Y04001`이 **균형패널 3종 어디에도 없다(리더 실측: 부재)**. RE 프로빗·FE 로짓·H-가설·forest plot이 존재하지 않는 변수에 의존. `[리더 실측]`
- **우려 2(시변 임금 종속변수 오식별)**: DS-B long 패널의 시변 종속 후보 `Y08031`은 코드북상 '배우자 고용형태'(범주형), `Y08035`는 '배우자 월소득'(소수 기혼 하위표본 7차 76→11차 453명)이다. 본인 노동소득의 차수반복 변수는 균형패널에 없다. 진짜 시변 임금은 `직업력 종단 데이터(2-9차)`로 구성해야 하는데 현재 fallback으로만 처리. `[검증반영]`
- **우려 3(Python 실행성 과대표기)**: RE 프로빗을 🟢(Python 실행)로 표기하나 statsmodels에 빈도주의 RE 프로빗이 없다(가용: ConditionalLogit=FE로짓, GEE, BinomialBayesMixedGLM=베이지안 RE로짓). 동적 GMM도 `linearmodels.IVGMM`은 횡단 IV이지 AB/시스템 GMM이 아니며 `pydynpd` 미설치. `[검증반영]`
- **우려 4(검정-표본 정합)**: 패널 단위근(IPS/LLC)은 실측 T(중앙값 3, ≥8차 보유 10명)에서 적용 불가. DS-A 단면 N(≈2,349)과 DS-B within식별 N(≈1,022~1,588)을 구분하지 않음. `[검증반영]`
- **경미 오류**: wave→연도 변환식 `year=wave+1`은 차수를 줄 뿐 실연도(2004+j)가 아님.

## 5. 종합 판정 및 후속 조치

### 5.1 판정: **조건부승인**
계획의 골격(데이터 사실·코호트 정의·패널 방법론·논문 플로우·시각화·정성보완)은 요구사항을 충실히 충족하며 데모로 가져갈 가치가 충분하다. 다만 **데모 실행 직전에 반드시 수정해야 할 2개 높음 이슈(I-1 pyreadstat, I-2 F11Y04001)**가 있어 무조건 승인은 부적절하다. 이들은 모두 리더가 직접 파일을 열어 확정한 사실이며, 정정하면 오히려 데모 품질이 향상된다. 따라서 반려가 아닌 조건부승인이 타당하다.

### 5.2 must_fix (Planning_v1.0.md 확정 전 필수)
1. **pyreadstat 작동 사실 반영**: 1차 소스를 `.SAV→pyreadstat.read_sav`(실패 시 xlsx fallback)로 격상, 값라벨 자동부착을 정제 단계 시연 포인트로. 세션정보에 pyreadstat 1.1.9 기재.
2. **이항 취업 성과 재정의**: `F11Y04001` 폐기. `BYJ107009`(종사상지위)·`BYJ105014/205014`(일자리형태) 또는 13차 Q-블록/직업력 종단으로 취업더미 구성, 실측 유효N·값라벨 확정.
3. **시변 임금 종속변수 교체**: DS-B 시변 임금은 `직업력 종단(2-9차)` J024/J023로 본설계 승격. `Y08031/Y08035`는 '배우자 소득(보조)'로 라벨 정정(Data_exploration·Method 동반 수정).
4. **본조사 연도 통일**: 전 보고서를 '균형패널=2004~2016 / 본조사=2019 추적조사'로 일치(AGE 근거 각주).
5. **매칭맵 예시 정정**: `F11Y08049` → 5차 `F4Y08060`, 8차 `F7Y08049` + §3.4 전 셀 재대조.

### 5.3 should_improve (개선권고)
1. RE 프로빗 🟢 표기 현실화(FE 조건부로짓/GEE 또는 베이지안 RE로짓), 동적 GMM은 🟡(코드만)로 강등 + pydynpd 설치를 선결조건으로 명시.
2. 패널 단위근 검정을 배터리에서 제거하거나 '코드예시·결과해석 금지'로 격하(실측 T 중앙값 3과 정합화).
3. DS-A(단면 N≈2,349)와 DS-B(within식별 N≈1,022~1,588) 표본수를 기초통계·검정표에서 명시 분리.
4. wave→연도 변환식 정정(`연도=2004+j`), 시간축에 차수·실연도 병기.
5. 경미 수치 정정: 가이드 57행, TXT 978, 직업 잔여 73, LAYOUT 예시 코호트 정합.
6. 가중치 8,257행 ↔ 균형패널 3,150행 부분집합 관계·재정규화 정책을 데모 전 1회 점검.

### 5.4 strengths (강점)
1. **데이터 사실 기반이 견고**: 표본·코호트·임금·SES 기초통계가 리더 재산출과 일치.
2. **방법론 설계의 깊이**: Mundlak/CRE를 시불변 SES 식별의 종착 모형으로 선택한 논리가 본 데이터 구조에 정확히 부합.
3. **AI 논문 플로우의 구체성**: 9단계 표·소요시간·자연어질문 루프가 '낙오자 없이' 취지를 잘 구현.
4. **정직한 한계 처리**: 인과 단정 회피, 정성·혼합방법 보완으로 Requests의 '미래예측 정성보완' 취지 반영.
5. **검정 직접구현의 시연 가치**: BP-LM·Hausman·Wooldridge·CD를 공식 기반 직접 코딩하는 설계가 'AI가 통계량을 코딩'하는 데모 포인트로 우수.
