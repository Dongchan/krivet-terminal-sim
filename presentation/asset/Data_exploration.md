### 1.2 기타 주요 데이터

| 항목(상대경로) | shape | 비고 |
|---|---|---|

> **1~12차 원자료 형식(실측):** SAS/SPSS/TXT 3종 동시 제공. TXT는 **고정폭(fixed-width)** 으로 모든 행이 정확히 **978자**(정정), 탭·콤마 없음. 파싱하려면 LAYOUT의 `열`(예: BYSID=1-4, BYHID=5-9, GENDER=17-18) 컬럼 위치가 반드시 필요. SPSS `.sav`는 코호트별 폴더(`고등학교 3학년생 코호트` / `중학교 3학년생 코호트`)·조사대상별 파일(student/household/teacher/highschool 등)로 분리.
> → **데모에서는 1~12차 원자료를 직접 파싱하지 않고, KRIVET이 이미 통합·정제한 균형패널 3종을 1차 소스로 사용**하는 것을 권고(아래 §8).

## 3. 변수명 규칙 해독 & 접두사(차수)별 변수개수표 (실측)

### 3.1 명명 규칙
- **접두사 = 변수 출처/대표차수 인코딩:** `BY` = 기준년도(2004, base year), `F1`~`F12` = 후속 차수(F11 = 11차 추적). (과업서의 'BY=2004, F=후속'과 일치 확인.)
- **본체 패턴:** `F11Y01103` = F(후속){11}(차수) + Y(조사유형) + 01(블록) + 103(문항). 끝의 소문자 `c`/`C` = 코드형(분류코드) 변수.
- **균형패널의 대표 변수명 규칙(중요):** 매칭맵(`Balanced Panel Data 매칭맵.xlsx`)상 균형패널 컬럼명은 **가장 마지막(최신) 차수의 변수명을 대표명으로 채택**한다(예: 첫직업 관련 변수는 모두 `F11Y…` 또는 `BYJ…`로 통합). 즉 **차수별로 별도 컬럼이 모두 존재하는 것은 아님**(§4).
- 식별/기초 변수 8개와 일부 `Q*`(13차 본조사 문항 직결분) 및 `*_차수`(연결 차수)는 접두사 규칙 밖.

- **wide 포맷 확정:** 한 행 = 한 개인, 차수 정보는 컬럼 접두사로 펼쳐짐.

## 4. 패널 구조 평가 & wide → long 변환 (실제 시연)

### 4.1 균형패널의 두 가지 '차수' 구조 (실측)
1. **통합형(학력·직업):** 동일 문항이 여러 차수에서 수집됐어도 균형패널에는 **하나의 대표 컬럼**으로만 존재(예: '현재 일자리 유무'의 차수별 컬럼 `F4Y04001…F11Y04001`은 데이터에 **개별로 존재하지 않음** — 매칭맵에만 출처로 기록). → 이 블록은 **이미 1회 관측으로 collapse**된 상태.
2. **반복형(기타):** 같은 문항이 **차수별 별도 컬럼**으로 모두 존재(접미사 동일, 접두사만 F3→F11). → **wide_to_long으로 long 변환 가능.**

기타파일에서 **3개 차수 이상 반복**되는 변수(suffix) = **23개** 확인. 대표 예:

| suffix | 라벨(코드북) | 존재 차수 | 컬럼 예 |
|---|---|---|---|
| `Y09001` | 여가시간-평일 | 3,4,5,6,7,8,9,10,11 | F3Y09001 … F11Y09001 |
| `Y09002` | 여가시간-휴일 | 3~11 | F3Y09002 … |
| `Y08035` | **배우자**의 월평균 소득(본인 소득 아님) | 7~11(+초기 상이코드) | F7Y08035 … F11Y08035 |
| `Y08041/42` | 부모집/하숙·자취 생활비 | 3~11 | … |
| `Y08031` | **배우자** 고용형태(범주형, 본인 소득 아님) | 5~11 | … |

> **[정정]** 초판은 `Y08031`을 '상용직 임금근로자(소득)', `Y08035`를 '배우자 월평균 소득'으로 적었으나, 코드북 재대조 결과 **둘 다 본인 노동소득이 아니다**(`Y08031`=배우자 고용형태(범주형), `Y08035`=배우자 월소득, 기혼 하위표본). 따라서 **DS-B의 진짜 시변 임금 종속변수는 `직업력 종단 데이터(2-9차년도)`의 `J024`(월평균 임금)·`J023`(월평균 총 소득)**로 구성한다(아래 §4 권고 및 Method §2 참조). `Y08*`는 가구·생애 보조 변수로만 사용.

### 4.2 실제 reshape 시연 결과 (여가시간-평일 `Y09001`, 차수 3~11)

```python
wave_cols = [f"F{w}Y09001" for w in range(3,12)]      # 9개 차수 컬럼
sub = other[['BYSID','GENDER','BYSCLASS'] + wave_cols].rename(
        columns={f"F{w}Y09001": f"leisure_{w}" for w in range(3,12)})
long = pd.wide_to_long(sub, stubnames='leisure', i='BYSID', j='wave', sep='_').reset_index()
```

- **wide (3,150 × 12) → long (28,350 × 5)** 변환 **성공**. (3,150명 × 9차수 = 28,350행)
- long 스키마: `BYSID(i), wave(t), BYSCLASS, GENDER, leisure(y)` → **개인×차수 패널 구조 확보, statsmodels/linearmodels의 MultiIndex(entity=BYSID, time=wave) 추정 입력으로 즉시 사용 가능.**
- **결론: 균형패널은 패널 계량분석을 위해 long 변환이 필요하며, 기타파일 반복변수에 대해 변환이 실증적으로 가능함을 확인.**

> **데모 설계 권고(정정):** 노동시장 성과(임금)의 **진짜 차수반복(시변) 패널**은 **별도 제공된 `직업력 종단 데이터(2-9차년도)`를 BYSID로 병합**해 구성한다. 본 에이전트 실측: 이 파일은 long 포맷(115열 × 약 21,302행, 키 `BYSID`), 일자리-spell 단위로 `A01`(일자리 순서)·`A02`(조사 차수/년도)·`J001/J002`(시작·종료 시기)·**`J024`(월평균 임금)·`J023`(월평균 총 소득)**·`S01~S09`(차수별 조사성공 플래그)를 보유한다. 기타파일의 `Y08031/Y08035`는 본인 소득이 아니라 **배우자** 변수이므로 시변 임금 종속변수로 쓰지 않는다.

### 5.1 전체 결측률 (NaN 기준)

## 8. 데모용 권고 요약

1. **1차 소스:** KRIVET 통합·정제된 **균형패널 3종 xlsx**(원자료 TXT 고정폭 직접파싱 회피).
2. **표본:** n=3,150(균형패널), 식별자 `BYSID`. 세 파일 `BYSID`로 머지 가능.
3. **코호트:** `COHORT`(본조사) 또는 `BYSCLASS` 매핑으로 **중3(753) vs 고3(1,485)** 정의. 신규·보정표본(912) 포함 여부·가중치는 분석설계에서 결정.
4. **패널 차원:** 진정한 차수반복은 **기타파일**(또는 직업력 종단데이터 병합). wide→long(`wide_to_long`)로 entity=BYSID, time=wave 구성.
5. **전처리 필수:** **음수 = 결측** 치환. 결측은 '이탈'이 아닌 '문항 도입시점/비해당' 구분.
6. **핵심 분석 변수(간소화, 지시 ㉮):** 데모 기본은 **단일 결과변수 = 로그 월임금**(DS-A `BYJ205034` / DS-B 직업력 `J024`), 핵심 독립 = **가구소득 SES `BYH20001`** + 대졸더미 + 코호트 + 성별 + SES×코호트. 취업더미 `BYJ107009`(`F11Y04001` 폐기)·합성 SES·수능 등은 **선택(심화)**.
7. **분석셋 별도 파일 산출(지시 ㉯):** 정제·reshape를 거친 **DS-A(wide)·DS-B(long)**를 `Analysis_Demo/data/`에 **CSV+DTA**로 저장(`keep_analysis_wide.{csv,dta}`, `keep_analysis_long.{csv,dta}`, `data_dictionary.csv`) → 사람·R·Stata가 같은 파일로 검증.
8. **작업 디렉터리(지시 ㉰):** 데모의 모든 생성물(스크립트·데이터·표·그림·검증코드·로그)은 프로젝트 루트 **`Analysis_Demo/`**에 둔다. 원자료(`KEEPI_Data_Codebook_1_to_13/`)는 **읽기 전용**.
