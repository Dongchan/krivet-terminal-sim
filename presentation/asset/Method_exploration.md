## 0.5 간소화 핵심 노선 (사용자 지시 ㉮ — 데모 기본 실행 경로)

데모는 아래 **핵심만 실행**한다. §3~§7의 나머지 모형·검정·시각화는 **선택(심화) 메뉴**(시간 여유 시/부록)다. 비전공자가 한 줄기("검정→모형선택→해석")를 끝까지 따라오게 하는 것이 목적이다.

| 항목 | 핵심 노선(데모 기본) | 선택(심화) |
|---|---|---|
| 결과변수 | **로그 월임금 1개**(DS-A `BYJ205034` / DS-B 직업력 종단 `J024`) | 취업더미 `BYJ107009`, 일자리 질, 첫직업임금 |
| 설명변수 | **가구소득(로그) SES** + 대졸더미 + 코호트 + 성별 + **SES×코호트** | 합성 SES/PCA, 부모학력, 수능, 매개 |
| 모형(4) | **Pooled → RE → FE → Mundlak(★종착)** | FD, MixedLM 성장곡선, 이항(FE조건부로짓/GEE/베이지안RE로짓), 동적GMM |
| 검정(3) | **F · Breusch–Pagan LM · Hausman** + 군집강건SE | Mundlak Wald, Wooldridge, 수정Wald, Pesaran CD, VIF |
| 기초통계표(2) | between/within 분해 · 코호트 요약 | 균형/이탈표, 상관표 |
| 패널 시각화(3) | V1 스파게티+평균 · V2 코호트추세 · V4 전이행렬 | V3 분포, V5 결측, V6 SES구배 |
| 결과 시각화(2) | R1 forest · R2 FE/RE/Mundlak 비교 | R3 한계효과, R4 상호작용(권장), R5 성장곡선, R6 이동성행렬 |
| 분석셋(지시 ㉯) | **DS-A/DS-B를 `Analysis_Demo/data/`에 CSV+DTA 별도 파일로 산출**(검증 가능) | — |
| 작업 디렉터리(지시 ㉰) | **모든 생성물은 `Analysis_Demo/`** | — |

> 본 §0.5는 §1~§10의 풍부한 카탈로그 중 **데모로 실제 실행할 최소 집합**을 고정한 것이다. 아래 상세 설계는 그 근거와 '선택' 확장 메뉴를 함께 제공한다.

## 1. 데모 연구질문·가설 구체화

### 1.1 데모 연구질문 (확정)

> **"가구의 사회경제적 지위(SES)와 청소년기 교육성취가 청년기 노동시장 성과(임금·취업·일자리 질)에 미치는 영향은 무엇이며, 이 영향(=사회이동성의 강도)은 중3 코호트와 고3 코호트 사이에서 다른가?"**

이는 세대 간 이동성(출신 배경 → 본인 성과)과 세대 내 이동성(첫직업 → 마지막직업 임금 성장)을 모두 포괄하도록 설계한다.

### 1.2 '성과', 'SES', '사회이동성'의 운영적 정의 — 대안과 권장안

각 개념을 2~3개 대안으로 제시하고, 실측 변수코드와 1차 권장안(★)을 표시한다.

#### (a) 노동시장 '성과(Outcome)'

| 대안 | 변수코드(실측) | 척도 | 유효 N | 데모 적합성 |
|---|---|---|---|---|
| ★A1. 마지막직업 월임금(연속) | `BYJ205034` | 만원/월, 평균 189.6 | 2,349 | **권장.** 연속 → OLS/FE 직접 적용, 임금성장 스토리와 결합 |
| A2. 첫직업 월임금(연속) | `BYJ105034` | 만원/월, 평균 117.1 | 2,023 | 진입 시점 성과. A1과 쌍으로 '세대 내 이동' 구성 |
| A3. 취업/일자리 질(이진·서열) | **`BYJ107009`(종사상 지위 1~5)** 기반 임금근로 취업더미, `BYJ105014/205014`(상용1/임시2/일용3) | 이진/서열 | 정규직 더미 등 구성, 이항·순서형 패널 시연용 (★`F11Y04001` 폐기: 균형패널 부재) |
| A4. 시변(차수반복) 임금 | **직업력 종단 `J024`(월평균 임금)/`J023`(월평균 총 소득)** | 연속 | long(spell) | **DS-B 진짜 시변 종속변수**. `Y08031/Y08035`(배우자 변수) 폐기 |

> 권장(정정): **주(主)성과 = `BYJ205034`(임금, 연속)**, 부(副)성과 = `BYJ107009` 기반 **취업더미**(이진) + **직업력 종단 `J024`** 시변 임금(long). 임금은 로그변환(`ln_wage`) 후 분석(분포 비대칭·해석 탄력성). **★초판이 지정한 취업변수 `F11Y04001`은 균형패널 3종 전부 부재(실측), 시변 임금 `Y08031/Y08035`는 본인이 아닌 배우자 변수 → 모두 폐기·교체.**

#### (b) 가구 'SES'

| 대안 | 변수코드(실측) | 구성 | 데모 적합성 |
|---|---|---|---|
| ★B1. 합성 SES 지수 | `BYH20001`(가구소득)+`BYH26006`/`BYH27006`(부/모학력)+`BYH12001`/`BYH16001`(부/모 고용형태) 표준화 합성 | 다차원 | **권장.** 단일변수 측정오차 완화, z-score 합성 또는 1주성분(PCA) |
| B2. 가구소득 단일 | `BYH20001`(평균 254.9만원, N 2,923) | 연속 | 해석 단순. 단 코드북-데이터 불일치(연속 vs 6구간) 확인필요 |
| B3. 부모 최고학력 | max(`BYH26006`,`BYH27006`)(1~7척도, 데이터 8·9 존재) | 서열 | 세대 간 학력이동 직관적. 값체계 확인필요 |

> 권장: **B1 합성 SES**(메인) + **B3 부모학력**(이동성 전이행렬용). SES는 1차 가구조사(2004) 기반 → **시불변 처리**(가구조사는 기존패널 1~4차 한정). 보정패널(BYSCLASS 4·5)은 SES 부재 → 제외.

#### (c) '사회이동성(Social Mobility)'

| 대안 | 운영적 정의 | 사용 변수 | 데모 적합성 |
|---|---|---|---|
| ★C1. 세대 간 절대·상대 이동 | 부모 SES → 본인 성과(임금/학력)의 회귀계수·탄력성 = '이동성의 약함'(계수 클수록 이동성 낮음) | 부모 `BYH*` → 본인 `BYJ205034`/`Q1` | **권장.** 회귀계수가 곧 이동성 측정. 코호트 상호작용으로 비교 |
| C2. 세대 간 전이행렬 | 부모학력 5분위 × 본인학력 5분위 전이확률 행렬 | `BYH26006` × `Q1`(최종학력) | 시각화(히트맵)에 최적. 직관적 |
| C3. 세대 내(생애) 이동 | 첫직업→마지막직업 임금분위 변화, 또는 long 소득 성장곡선 | `BYJ105034`→`BYJ205034`, 직업력 long | 패널 성장곡선 모형과 직결 |
| C4. 이동성 인식(주관) | "성공 요인" 응답 | `F11Y13009`(1=부모도움…3=본인노력) | 정성·혼합방법 보완(§10) |

> 권장: **C1(계수 기반) + C2(전이행렬 시각화) + C3(생애 임금이동)** 3종 병행. C4는 정성 보완.

### 1.3 가설 (검정 가능 형태)

| # | 가설 | 검정 모형 |
|---|---|---|
| H1 | 가구 SES↑ → 청년기 임금↑ (β_SES > 0) | Pooled OLS / RE / Mundlak |
| H2 | 청소년기 교육성취(수능·최종학력)↑ → 임금↑, 그리고 SES→임금 효과의 일부를 **매개** | 경로분석(2단계 OLS) |
| H3 | SES→성과 효과(이동성 약함)는 **중3 코호트 < 고3 코호트** (또는 반대) — 코호트 간 차이 존재 | SES×코호트 상호작용항 |
| H4 | 생애 내 임금은 시간(경력)에 따라 증가하며, 증가 기울기는 SES에 따라 다르다 | 성장곡선(혼합효과), 시간×SES |
| H5 | 첫직업 임금의 출신배경 격차는 마지막직업에서 축소/유지된다(생애 이동) | FD / FE 패널 |

## 2. 데이터 준비 설계

### 2.1 두 갈래 분석 데이터셋

탐색 결과(학력·직업파일=통합형 횡단, 기타파일만 차수반복)에 따라 **두 데이터셋을 병행 구축**한다.

| 데이터셋 | 구조 | 단위 | 용도 | 주 소스 |
|---|---|---|---|---|
| **DS-A (wide 통합)** | 1인 1행, n=3,150 | 개인 | 세대 간 이동성 경로모형(횡단·준종단), 전이행렬 | 학력·직업·기타 파일 BYSID 병합 + 수능 + 13차 본조사 |
| **DS-B (long 패널)** | person-spell/person-year, ≈ N×T(within식별 표본 N≈1,022~1,588, person-year≈5,853) | 개인×차수 | 패널 계량(FE/RE/성장곡선), 검정 배터리 시연 | **직업력 종단(2-9차) `J024` 임금**(주 시변종속) + 기타파일 보조 반복변수(`F{w}Y…`) |

> **분석셋을 별도 파일로 산출(지시 ㉯):** DS-A/DS-B는 정제·재구성 후 `Analysis_Demo/data/`에 **CSV(범용·가독)와 DTA(Stata)**로 저장한다(`keep_analysis_wide.{csv,dta}`, `keep_analysis_long.{csv,dta}`, `data_dictionary.csv`). 이후 모든 추정·검정·검증은 이 파일을 입력으로 하며, `verify.R`(→ csv)·`verify.do`(→ dta)도 **같은 파일**을 읽어 도구 간 결과를 교차검증한다. 정제 로직과 분석 로직을 파일로 분리해 **사람이 직접 열어 검증**할 수 있게 한다.

### 2.2 wide → long reshape (DS-B 핵심)

탐색에서 실증 성공(여가 `Y09001`, 3,150×12 wide → 28,350×5 long). 데모 본분석에서는 **소득/노동 변수**로 동일 절차 적용.

**(주 경로) 직업력 종단(2-9차) 병합으로 본인 시변 임금 패널 구성 — 실측 구조 확인:**
파일 `…/직업력 종단 데이터(2-9차년도)/DATA_직업력 종단 데이터(Ver_20141114).xlsx`는 **이미 long(일자리-spell) 포맷**(115열 × 약 21,302행, 키 `BYSID`)이다. 핵심 변수: `A01`(일자리 순서)·`A02`(조사 차수/년도)·`J001`/`J002`(시작·종료 시기)·**`J024`(월평균 임금)·`J023`(월평균 총 소득)**·`S01~S09`(차수별 조사성공). spell을 person-year로 집계(A02 기준 연도별 주 일자리 `A06`)하면 `BYSID×year` 패널이 된다.

```python
# 🟢 Python — 직업력 종단(주 경로): 이미 long, 연도별 주 일자리만 추출
import pandas as pd
emp = pd.read_excel(".../DATA_직업력 종단 데이터(Ver_20141114).xlsx")
emp = emp[emp["J024"] >= 0]                        # 음수 결측코드 제거
emp = emp[emp["A06"] == 1]                          # 년도별 주요 일자리만(중복 spell 정리; 코드값 확인필요)
emp = emp.rename(columns={"A02":"year","J024":"wage"})
panel = emp.set_index(["BYSID","year"])             # entity, time → linearmodels 입력
```

## 3. 패널 모형 후보와 적용 상황

각 모형의 추정식·가정·장단점·데모 적합성. (i=개인 BYSID, t=차수 wave, y=성과(예 ln임금), x=시변 통제, z=시불변 SES.)

> **간소화(지시 ㉮):** 데모 기본 실행은 §0.5의 **핵심 4모형(Pooled→RE→FE→Mundlak)**뿐이다. 아래 카탈로그의 나머지(FD·MixedLM·이항·동적GMM)는 **선택(심화)** — 근거 비교용으로 둔다.

### 3.1 모형 카탈로그

| 모형 | 추정식(개념) | 핵심 가정 | SES(시불변) 식별? | 장점 | 단점 | 데모 적합성 |
|---|---|---|---|---|---|---|
| **Pooled OLS** | y_it = α + βx_it + γz_i + ε_it | 개체효과 없음, ε⊥x | ✅ | 단순, SES계수 직접 추정 | 개체이질성·자기상관 무시 → 편의 | 베이스라인, 검정 출발점 🟢 |
| **고정효과 FE(within)** | (y_it−ȳ_i)=β(x_it−x̄_i)+u_it | α_i가 x와 상관 허용 | ❌(z 소거됨) | 누락 시불변 교란 통제, 인과 근접 | **시불변 SES 계수 추정 불가** → 이동성 주효과 소거 | 시변 통제용·강건성. **단독으론 SES 못 봄** 🟢 |
| **확률효과 RE** | y_it=α+βx_it+γz_i+(α_i+ε_it), α_i⊥x | α_i가 모든 x·z와 무상관 | ✅ | SES 추정 가능, 효율적 | 가정 깨지면 편의(Hausman으로 검증) | **SES 효과 보려면 핵심** 🟢 |
| **1차차분 FD** | Δy_it=βΔx_it+Δε_it | FE와 유사, T=2 동치 | ❌ | 단위근·추세 제거, 측정오차 진단 | z 소거, ΔΔ에 노이즈 증폭 | 첫직업→마지막직업 2시점 변화에 적합 🟢 |
| **Mundlak(상관임의효과 CRE)** | y_it=α+βx_it+λx̄_i+γz_i+(α_i+ε_it) | α_i=λx̄_i+a_i (a_i⊥x) | ✅ | **FE의 식별력 + RE의 z계수 동시 확보**, Hausman 대체 | x̄_i 추가로 다중공선성 주의 | **1차 권장.** SES(시불변)+within 모두 시연 🟢 |
| **동적패널(Arellano-Bond/시스템 GMM)** | y_it=ρy_i,t−1+βx_it+α_i+ε_it | 시차종속·내생성, 적률조건 | 부분 | 임금의 상태의존성·동태 포착 | **T 과소(중앙값 3)로 시차종속 추정 불안정·약도구** | 임금경로 동학(보조). **🟡 코드 산출물만**(linearmodels.IVGMM은 횡단 IV-GMM이라 AB/시스템 GMM 아님, pydynpd 미설치 → 실연하려면 `pydynpd` 설치 선결). Stata `xtabond2` |
| **다층/성장곡선(혼합효과)** | y_it=(γ00+u0i)+(γ10+u1i)·time_it+βz_i+ε_it | 무선절편·기울기 정규 | ✅ | **생애 임금궤적·기울기 이질성**, 시간×SES 상호작용 | 분포가정·수렴 이슈 | **H4(이동성 기울기)에 최적** 🟢 statsmodels `MixedLM`, 🟡 R `lme4::lmer` |
| **이항-FE 로짓(조건부)** | P(y=1)=Λ(βx_it+α_i) | 조건부우도, 시간내 변동 필요 | ❌ | 시불변 교란 통제 | y가 시간 불변인 개체 탈락(표본축소) | 취업여부 강건성 🟢 statsmodels `ConditionalLogit` |
| **이항-RE(프로빗/로짓)** | P(y=1)=Φ/Λ(βx_it+γz_i+α_i) | α_i 정규·⊥x | ✅ | SES 효과 추정, 한계효과 | 가정 민감 | **취업(이진) 보조.** 🟢 베이지안 RE로짓 `BinomialBayesMixedGLM`(statsmodels), 🟡 R `glmer(probit)`·Stata `xtprobit,re`. ⚠️ **빈도주의 RE 프로빗은 statsmodels 미제공**(정정) → 메인은 아래 FE 조건부로짓/GEE |

### 3.2 데모 모형 선택 논리 (요지)

1. **SES는 시불변**(1차 가구조사) → **순수 FE는 SES 주효과를 소거**. 따라서 이동성(SES→성과)을 보려면 **RE 또는 Mundlak**이 핵심.
2. 그러나 RE의 무상관 가정은 깨지기 쉬움 → **Mundlak/CRE**로 within·between을 분리하고 SES 계수를 그대로 보존(★1차 권장).
3. 시변 통제(경력·결혼·지역)는 FE/within으로 처리, 생애 기울기 이질성은 **성장곡선**으로.
4. 취업(이진)은 **FE 조건부로짓(`ConditionalLogit`)/GEE 메인 + 베이지안 RE로짓(`BinomialBayesMixedGLM`) 또는 R `glmer`·Stata `xtprobit,re`(🟡) 강건성**(빈도주의 RE 프로빗은 statsmodels 미제공이라 메인에서 제외).
5. 동적 GMM은 임금 상태의존성 데모용 보조이나 **T 과소(중앙값 3)로 추정 불안정** → 🟡 코드 산출물로만 제시(실연 시 pydynpd 설치 선결).

## 4. 방법론 선택을 위한 검정 통계 (검정-모형 매핑)

> 과업서 4) 핵심 요구. 각 검정의 귀무가설·해석·판단기준·실행도구를 매핑한다.
> 🟢=Python 실제 실행 가능, 🟡=R/Stata 검증용 산출물.

| # | 검정 | 비교/목적 | 귀무가설 H0 | 기각 시 함의 | 판단기준 | Python(🟢) | R `plm`(🟡) | Stata(🟡) |
|---|---|---|---|---|---|---|---|---|
| 1 | **F검정(개체효과)** | Pooled vs FE | 모든 α_i 동일(개체효과 없음) | FE 필요 | p<0.05 → FE | linearmodels `PanelOLS(...,entity_effects=True).f_pooled` (F-test for poolability) | `pFtest(fe, pooled)` | `xtreg, fe` 후 하단 F |
| 2 | **Breusch–Pagan LM** | Pooled vs RE | Var(α_i)=0(개체분산 없음) | RE 필요 | p<0.05 → RE | statsmodels 보조/직접구현(점수검정) | `plmtest(pooled, type="bp")` | `xttest0`(`xtreg, re` 후) |
| 3 | **Hausman** | FE vs RE | RE 추정량 일치(α_i⊥x) | FE 채택(RE 편의) | p<0.05 → FE | linearmodels `compare()`+수동 Hausman 통계량 구현 | `phtest(fe, re)` | `hausman fe re` |
| 4 | **Mundlak(Wald)** | RE↔FE 등가 진단 | x̄_i 계수 전부 0(=RE 적합) | CRE/FE 선호 | x̄_i 결합유의 p<0.05 | `RandomEffects`에 x̄_i 투입 후 Wald | `pwartest`/수동 | `mundlak`(사용자), `xtreg`+`testparm` |
| 5 | **Wooldridge(1차 자기상관)** | 패널 직렬상관 | ρ=0(잔차 무상관) | 클러스터/HAC SE 필요 | p<0.05 → 상관 존재 | FD잔차 회귀로 직접구현 | `pwartest`/`pbgtest` | `xtserial`(사용자) |
| 6 | **수정 Wald(그룹간 이분산)** | FE 잔차 이분산 | 모든 개체 σ²_i 동일 | 강건SE 필요 | p<0.05 → 이분산 | 직접구현(개체별 분산) | 수동 | `xttest3`(사용자) |
| 7 | **Pesaran CD(횡단면 의존)** | 잔차 횡단상관 | 횡단면 독립 | 시간효과/CCE 필요 | \|CD\|>1.96 | 잔차상관 평균 직접구현 | `pcdtest(model)` | `xtcsd`(사용자) |
| 8 | ~~**패널 단위근(IPS/LLC)**~~ | ~~비정상성~~ | — | — | — | **본 데이터 T 과소(중앙값 3, ≥8차 보유 10명)로 비적용 → 검정 배터리에서 제외**(정정). 코드예시·결과해석 금지 | — | — |
| 9 | **VIF(다중공선성)** | 회귀 진단 | (해당없음) | 공선성 처리 | VIF>10 주의 | statsmodels `variance_inflation_factor` | `car::vif` | `estat vif` |

> **Python 구현 가능성 메모(🟢):** F검정·VIF·MixedLM·ConditionalLogit·PanelOLS·RandomEffects는 statsmodels/linearmodels에서 **직접 제공**. BP-LM·Hausman·Wooldridge·수정Wald·Pesaran CD는 표준 함수가 없어 **공식 기반 직접 구현(수십 줄)**으로 데모 — "AI가 검정 통계량을 직접 코딩"하는 **시연 가치가 큰 부분**. R `plm`/Stata 대응 명령은 산출물로 동봉해 교차검증(값 비교)을 보여준다.

### 4.1 검정 → 모형 선택 의사결정 흐름

```
[1] F검정(pooled vs FE)        → 유의 → 개체효과 존재(Pooled 부적합)
[2] BP-LM(pooled vs RE)        → 유의 → 개체효과 존재(RE 후보)
[3] Hausman(FE vs RE)          → 유의 → FE / 비유의 → RE
[4] Mundlak                    → x̄_i 유의 → CRE(FE식별)+SES계수 보존  ★데모 권장 종착
[5] Wooldridge·[6]수정Wald·[7]CD → 유의 → (계수는 유지) SE를 클러스터·Driscoll-Kraay로 교정
[9] VIF                        → 합성SES·상호작용 투입 전 공선성 점검
( [8] 패널 단위근은 T 과소로 본 데이터에서 제외 )
```
> **표본 분리(정정):** 검정 배터리는 데이터셋별로 표본이 다르다. **DS-A(단면 스냅샷, 임금 유효 N≈2,349)**: Pooled OLS·RE·Mundlak·VIF·between/within 분해 중심. **DS-B(직업력 long, within식별 N≈1,022~1,588, person-year≈5,853)**: F검정·BP-LM·Hausman·Wooldridge·수정Wald·CD를 적용. 동적·단위근 검정은 DS-B의 짧은 T로 적용하지 않는다.

> 결론 권장: 검정 결과와 무관하게 **데모 종착 모형은 Mundlak(CRE)** — FE의 식별력으로 within을 통제하면서 시불변 SES(이동성 주효과)를 동시에 추정하기 때문. SE는 **개체 클러스터 강건SE** 기본 적용.

### 5.2 코호트·성별·차수별 요약표

| 분할 | 행 예시 | 열(요약) |
|---|---|---|
| 코호트별 | 중3 / 고3-일반 / 고3-전문 (/ 신규) | n, 평균임금, 취업률, SES평균, 최종학력분포 |
| 성별 | 남(1,891) / 여(1,259) | 동일 |
| 차수별(long) | wave 3~11 | 유효 N, 평균소득, 결측률(=문항도입 가시화) |

### 5.3 패널 균형/이탈표

| 항목 | 내용 |
|---|---|
| 차수별 관측 패턴 | wave별 유효 N(예 `Y09001`: 715→3,127) + 패턴 빈도표(xtdescribe 형) |
| 균형도 | balanced 부분 vs 전체 unbalanced 관측 비율 |
| 주의 | '이탈'이 아니라 '문항 도입시점' 주석 명시 |

🟡 Stata 대응: `xtset BYSID wave; xtdescribe; xtsum`. 🟢 Python: `groupby` 패턴 카운트로 동등 재현.

### 5.4 상관표 설계

- SES 구성요소(`BYH20001`,`BYH26006`,`BYH27006`,`BYH12003`,`BYH16003`) 간 상관 → 합성지수·PCA 타당성.
- 핵심 변수(SES, 교육성취, 임금) 피어슨/스피어만 상관 + VIF 사전점검.

## 8. AI 활용 논문작성 데모 플로우

> 과업서 8)·요청 핵심. 'Raw → 정제 → 자연어질문 → 분석 → R·Stata 검증코드 → 해석' 전 과정.
> **간소화(지시 ㉮):** 아래 표의 4·5·6단계는 개념 흐름이며, **데모 기본 실행은 §0.5 핵심 노선**(기초통계 2표 + V1·V2·V4, 검정 F·BP-LM·Hausman, 모형 Pooled→RE→FE→Mundlak, R1·R2)으로 좁힌다. 모든 산출물은 `Analysis_Demo/`에, 분석셋은 `data/`에 별도 파일로 저장(지시 ㉯·㉰).

| 단계 | 활동 | AI 활용 포인트 | 산출물 | 예상 소요(데모) |
|---|---|---|---|---|
| 1. Raw 적재 | 균형패널 3종 xlsx 로드, BYSID 병합 | AI가 파일·시트 구조 자동 파악, 병합키 검증 코드 생성 | 병합 스크립트, 적재 로그 | 3~5분 |
| 2. 정제 | 음수→NaN, 코호트·표본정의, 변수 라벨 매핑 | 코드북 라벨 자동 적용, 결측규칙·표본정의 자연어→코드 | 정제 스크립트, 데이터 사전 | 5~8분 |
| 3. 자연어 질문 | "부모 소득이 높을수록 자녀 임금이 높은가? 중3·고3 차이는?" | 자연어 질문 → 변수선택·모형후보 자동 제안 | 연구질문·가설 표 | 3분 |
| 4. EDA·기초통계·시각화 | between/within, 코호트표, 스파게티/히트맵 | 기술통계·시각화 코드 일괄 생성·해설 | 기초통계표, 그림 V1~V6 | 5~8분 |
| 5. 검정 배터리 | F·BP-LM·Hausman·Mundlak·Wooldridge·CD·VIF | **검정 통계량 직접 구현 + 결과 해석** | 검정 결과표, 모형선택 근거 | 8~10분 |

| 7. **R·Stata 검증코드** | `plm`/`lme4`, `xtreg`/`xtprobit` 코드 산출 | 동일 분석의 R·Stata 코드 자동 생성(미실행, 산출물) | `verify.R`, `verify.do` | 3~5분 |

| 9. 재현성 패키징 | 스크립트·시드·세션정보·README | 재현 패키지 자동 구성 | 재현 번들 | 2~3분 |
