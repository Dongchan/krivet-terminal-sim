시작 안내서 1~6번을 Codex로 마치고, RISS API 신청과 Python 설치까지

이 페이지는

실습 당일에는 각자 PC에서 Codex로 프로젝트 폴더를 만들고, 통계 MCP를 연결하고, RISS 검색 결과를 CSV 파일로 저장합니다. 그날 바로 시작할 수 있도록 아래 네 가지를 미리 해 두세요. 설치 과정은 시작 안내서를 따르고, 이 페이지에는 그 안내서에 더해 할 일만 적었습니다.

준비물  Windows 10 이상 또는 macOS 13 이상 컴퓨터, 인터넷, 프로그램 설치 권한, 소속 기관 이름과 사업자등록번호(RISS 신청용) 예상 소요  약 1시간 30분~2시간 30분(RISS 심사를 기다리는 시간 제외)
표기 약속

Windows 와 Mac 표시는 해당 운영체제에서만 다른 부분입니다. 표시가 없으면 공통입니다.

RISS API 신청을 가장 먼저 하세요

RISS는 신청서를 낸 뒤 심사를 거쳐 인증키를 줍니다. 심사 기간이 따로 걸리니, 이 페이지를 받은 날 바로 신청해 두세요.

목차
  1. RISS API 이용 신청 (가장 먼저)
  2. 시작 안내서 1~6번을 Codex로
  3. Python 설치
  4. 마지막 점검
  5. 당일에 같이 할 것 (미리 안 해도 됨)

1RISS API 이용 신청 (가장 먼저)

RISS(학술연구정보서비스) 검색 API를 쓰려면 인증키가 필요합니다. 신청 방법은 지난 특강 후속자료에 화면과 함께 정리해 두었습니다. 그 페이지의 2·3단계만 따라 하세요.

  • 후속자료 2단계 · 신청 자격 확인
  • 후속자료 3단계 · 이용 신청서 쓰기
  • 기관 명의로 신청합니다. 신청서에 소속 기관 이름과 사업자등록번호를 적습니다.
  • 키는 사람마다 따로 받습니다. 신청 화면에 "인증키는 타인에게 양도 및 공유가 불가합니다"라고 적혀 있습니다. 동료의 키를 빌려 쓰지 않습니다.
  • 승인되면 영문 소문자와 숫자로 된 32자리 인증키를 받습니다.
키를 받으면 이렇게 보관하세요
  • 카톡, 메일, 공유 문서에 키를 적지 않습니다. 키가 보이는 화면을 캡처하거나 화면 공유하지 않습니다.
  • 메모장을 열어 키만 붙여 넣고, 시작 안내서 5번에서 만든 작업 폴더 안에 RISS_API.txt라는 이름으로 저장합니다. 당일에 이 파일을 씁니다.
후속자료 4단계는 읽어만 두고, 5단계부터는 하지 마세요

4단계(키 보안)는 키를 왜 조심해야 하는지 설명합니다. 5단계는 키를 손으로 환경 변수에 등록하는 방법인데, 이번 실습에서는 저장해 둔 키 파일을 Codex가 등록하도록 당일 같이 합니다. 이미 등록했다면 그대로 두어도 됩니다.

2시작 안내서 1~6번을 Codex로

시작 안내서는 Claude Code를 중심으로 쓰여 있습니다. 이번 실습은 Codex(ChatGPT를 터미널에서 쓰는 도구)로 하므로, 아래처럼 바꿔 읽으면서 1~6번을 마치세요.

  • 1번 LLM 구독하기: ChatGPT Plus(월 20달러) 이상을 구독합니다. Claude 구독은 이번 실습에 필요 없습니다.
  • 2번 Node.js 설치: 꼭 합니다. 3번에서 Codex를 npm으로 설치할 때 필요합니다. 설치한 뒤 Windows는 명령 프롬프트(cmd)를, Mac은 터미널을 새로 열어 node --version과 npm --version에 숫자가 나오는지 확인합니다. 설치에 시간이 꽤 걸리니 여유 있을 때 미리 해 두세요. Windows 설치 마지막의 '추가 도구 자동 설치'를 체크합니다(Python이 이때 함께 설치됩니다). 설치가 끝난 뒤 검은 창이 떠서 한참 더 설치하는데, 가장 오래 걸리는 부분이니 창을 닫지 말고 끝날 때까지 기다립니다.
  • 3번 CLI 도구 설치: 'Codex (ChatGPT를 터미널에서)' 부분만 따라 합니다. Windows는 명령 프롬프트(cmd)에서 npm install -g @openai/codex 한 줄, Mac은 그 아래 Mac 터미널 명령입니다. Claude Code는 설치하지 않아도 됩니다. 설치한 뒤 codex를 실행해 Sign in with ChatGPT로 로그인까지 마칩니다.
  • 4번 VS Code 설치, 5번 작업 폴더 만들기: 안내서 그대로 합니다.
  • 6번 VS Code 통합 터미널에서 실행: 마지막에 claude 대신 codex를 입력합니다. Windows는 안내서대로 VS Code 터미널을 cmd로 바꿔 둡니다(PowerShell에서는 npm으로 설치한 codex가 막힐 수 있습니다).
VS Code 터미널
> codex

Codex 화면이 뜨면 6번까지 끝입니다. 나올 때는 /quit을 입력합니다.

3Python 설치

실습에서 Codex가 검색 결과를 표로 정리하고 두 통계를 합치는 코드를 Python으로 만들어 돌립니다. 그래서 내 PC에 Python이 있어야 합니다.

먼저 Python이 이미 있는지 확인하세요

Windows 2번에서 Node.js를 설치하며 '추가 도구 자동 설치'를 체크했다면 Python이 함께 설치돼 있습니다. VS Code 터미널을 새로 열어 아래를 입력하고, Python 3. 으로 시작하는 숫자가 나오면 이 단계는 건너뜁니다.

Windows · 버전 확인
> python --version
Mac · 버전 확인
> python3 --version

Windows 위에서 숫자가 나오지 않을 때만 아래 순서로 설치합니다 (공식 문서 기준: Python install manager)

  1. python.org/downloads에 들어가 Python install manager를 내려받습니다.
  2. 받은 파일을 더블클릭하고 Install을 누릅니다.
  3. VS Code 터미널을 새로 열고 python을 입력합니다. 처음 실행하면 최신 Python을 내려받아 설치합니다. 안내가 나오면 그대로 진행합니다. PATH에 폴더를 추가할지 물으면 추가한다고 답합니다.
  4. 설치가 끝나면 python --version을 다시 입력해 숫자가 나오는지 봅니다.

Microsoft Store로 설치해도 같습니다. 단, python.org 것과 Store 것을 둘 다 설치하지는 마세요.

Mac python.org/downloads에서 macOS 설치 파일을 받아 설치하고, 터미널에서 python3 --version으로 확인합니다.

python을 입력했는데 Microsoft Store가 열리거나 '찾을 수 없다'고 나오면
  • 시작 버튼을 누르고 앱 실행 별칭을 검색해 앱 실행 별칭 관리를 엽니다. Python (default)가 켜져 있는지 봅니다. 이미 켜져 있으면 껐다가 다시 켭니다.
  • 새로 설치한 명령은 새로 연 터미널에서 인식됩니다. 그래도 안 되면 VS Code를 완전히 껐다 켭니다.

4마지막 점검

실습 전날까지 VS Code 터미널에서 아래 세 줄을 한 줄씩 입력해, 각각 버전 숫자가 나오는지 확인하세요.

Windows · 점검
> node --version
> codex --version
> python --version
Mac · 점검
> node --version
> codex --version
> python3 --version
  • □ node --version에 숫자가 나온다
  • □ ChatGPT Plus를 구독하고 codex 로그인을 마쳤다
  • □ VS Code 터미널에서 codex가 실행된다
  • □ python --version(Mac은 python3 --version)에 숫자가 나온다
  • □ RISS 인증키를 받아 작업 폴더에 RISS_API.txt로 저장했다 (아직 심사 중이면 신청을 마쳤는지만 확인)
