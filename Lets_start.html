컴퓨터를 다루는 데 익숙하지 않아도, 이 문서만 따라 하면 구독 → 설치 → 프로젝트 만들기 → 실제 분석 실행까지 혼자 해낼 수 있도록 만들었습니다. 명령어는 검은 칸(코드블럭)을 그대로 복사해서 붙여 넣으면 됩니다.

준비물  Windows 또는 Mac 컴퓨터, 인터넷, 설치 권한(관리자) 예상 소요  약 30~40분(다운로드 시간 포함)
표기 약속

Windows 와 Mac 표시는 해당 운영체제에서만 다른 부분입니다. 표시가 없으면 공통입니다. Ctrl 은 Mac에서 대개 ⌘(Command)로 바꿔 누르세요.

잠깐, '검은 칸(코드블럭)'은 이렇게 씁니다

이 안내서 곳곳의 검은 칸은 터미널에 넣을 명령입니다. 손으로 옮겨 적지 말고, 칸 오른쪽 위 '복사' 버튼을 눌러 복사하세요.

그다음 터미널에 붙여 넣고 Enter를 누르면 실행됩니다. 붙여넣기는 Windows 명령 프롬프트(cmd)에서 마우스 오른쪽 클릭 또는 Ctrl+V, Mac ⌘+V 입니다. 줄 맨 앞에 #로 시작하는 글씨는 설명(주석)이라 넣지 않아도 됩니다.

0시작하기 전에: 큰 그림

먼저 자주 나오는 세 단어만 짚고 갑니다. 지금 다 이해하지 않아도 됩니다.

  • LLM (Large Language Model) · ChatGPT, Claude 같은 '대화형 인공지능'입니다.
  • CLI (Command Line Interface) · 까만 '터미널' 화면에 명령어를 입력해 프로그램을 쓰는 방식입니다. LLM을 터미널에서 쓰면, 내 컴퓨터의 폴더와 파일을 직접 읽혀 작업시킬 수 있습니다.
  • IDE (Integrated Development Environment) · VS Code 같은 '작업 공간' 프로그램입니다. 파일 탐색기, 편집기, 터미널이 한 화면에 모여 있어 편합니다.

전체 흐름은 이렇습니다.

① LLM 구독 → ② Node.js 설치 → ③ CLI 설치(claude·codex) → ④ VS Code 설치 → ⑤ 작업 폴더 만들기 → ⑥ 터미널에서 LLM 실행 → ⑦ 마크다운으로 지시 작성 → ⑧ '@'로 파일 읽히기 → ⑨ 분석 실행

1LLM 구독하기

터미널용 LLM 도구는 보통 유료 구독 또는 API 키가 있어야 제대로 쓸 수 있습니다. 가장 많이 쓰는 두 가지를 준비합니다.

Claude (Anthropic)

  1. claude.ai 접속 후 가입(구글 계정 등으로 간편 가입 가능)
  2. 좌측 하단 프로필 → Settings → Billing에서 Pro 또는 Max 요금제 구독
  3. 터미널 도구 'Claude Code'는 이 구독(Pro/Max) 계정으로 로그인해 사용합니다.

ChatGPT (OpenAI)

  1. chatgpt.com 접속 후 가입
  2. Plus 또는 Pro 요금제 구독
  3. 터미널 도구 'Codex'는 이 ChatGPT 계정으로 로그인해 사용합니다.
왜 구독해야 하나요?

이 안내서가 쓰는 터미널 도구(Claude Code · Codex)는 무료 요금제로는 제대로 써볼 수조차 없습니다. 로그인해서 쓰려면 유료 구독(또는 API 사용)이 필요합니다. 그러니 둘 중 하나는 반드시 구독한 뒤 시작하세요. 데이터 분석처럼 길고 무거운 작업이면 더욱 그렇습니다.

2Node.js 설치 (CLI의 토대)

Claude·ChatGPT의 터미널 도구는 Node.js 위에서 npm이라는 설치 도구로 깔립니다. 그래서 Node.js를 먼저 설치합니다.

  1. nodejs.org 접속
  2. LTS(안정 버전) 버튼을 눌러 내려받기 Windows .msi · Mac .pkg
  3. 받은 설치 파일을 실행해 '다음'으로 진행합니다. Windows는 환경변수(PATH)가 자동 등록되고, 마지막의 '추가 도구 자동 설치'는 체크하는 걸 권장합니다(아래 설명).
Windows '환경변수' 설정은 자동입니다 (PATH)

기본 설정 그대로 설치하면 node·npm 명령이 아무 터미널에서나 되도록 환경변수(PATH)에 자동 등록됩니다. 별도의 '환경변수 설정 화면'이 따로 뜨지 않아도 정상이니 안심하세요. (설치 중 'Custom Setup' 단계의 Add to PATH 항목이 기본으로 켜져 있어서 그렇습니다. 일부러 끄지만 마세요.)

Windows '추가 도구 자동 설치'는 체크하는 걸 권장합니다

설치 마지막에 'Tools for Native Modules'(추가 도구 자동 설치) 체크박스가 있습니다. 데이터 분석을 하다 보면 Python 같은 도구가 어차피 필요한데, 이걸 체크하면 한 번에 깔아 주니 체크를 권장합니다.

체크하면 설치가 끝난 뒤 검은 PowerShell 창이 저절로 떠서 Chocolatey·Python 등을 한참(수 분 이상) 설치합니다. 처음 보면 당황스럽지만 오류도 바이러스도 아니라 정상이니, 끝날 때까지 두었다가 안내가 나오면 아무 키나 눌러 닫으세요. (용량이 크고 관리자 권한이 필요할 수 있습니다.)

설치가 끝나면 잘 깔렸는지 확인합니다. 터미널을 엽니다.

  • Windows Win+R 누르고 cmd 입력 후 Enter (또는 시작 메뉴에서 명령 프롬프트(cmd) 검색)
  • Mac 터미널(Terminal) 앱 실행
터미널 · 버전 확인
node --version
npm --version

각각 v22.x.x 처럼 숫자가 나오면 성공입니다.

'node를 찾을 수 없습니다' 라고 나오면

설치 후 터미널을 완전히 껐다 다시 켜세요. 새 프로그램 경로(PATH)가 적용되려면 재시작이 필요합니다. 그래도 안 되면 위 'Add to PATH'가 꺼진 채 설치된 경우이니, Node.js를 다시 설치하며 그 항목을 켜 주세요.

3CLI 도구 설치 (Claude·ChatGPT)

이제 터미널에서 쓸 LLM 도구를 설치합니다. 둘 다 설치할 필요는 없고, 구독한 쪽을 설치하면 됩니다.

먼저 '터미널'을 엽니다

아래 명령들은 모두 터미널(까만 창)에 입력합니다. Windows Win+R → cmd → Enter. Mac 터미널(Terminal) 앱 실행. (2단계에서 연 창을 그대로 써도 됩니다.) 명령을 입력(또는 붙여넣기)하고 Enter를 누르면 실행됩니다.

Claude Code (Claude를 터미널에서)

터미널 · 설치
npm install -g @anthropic-ai/claude-code

설치 후, 작업할 폴더에서 아래를 입력하면 실행됩니다.

터미널 · 실행 / 로그인
claude

처음 claude를 실행하면 계정 연결(로그인) 과정을 거칩니다.

  1. 로그인 방식을 묻습니다. 구독 계정으로 쓰려면 'Claude account' 쪽을 고릅니다(회사 API 키가 있으면 'Anthropic Console' 선택).
  2. 자동으로 브라우저가 열립니다. claude.ai에 로그인한 뒤 'Authorize'(승인)를 누릅니다.
  3. 브라우저가 안 열리면, 터미널에 표시된 인증 주소(URL)를 복사해 브라우저에 직접 붙여 넣으세요. 코드가 나오면 그 코드를 터미널에 붙여 넣습니다.
  4. 승인되면 터미널로 돌아와 연결 완료. 이후엔 다시 로그인할 필요 없이 바로 실행됩니다.
처음 실행 때 더 나올 수 있는 질문

색상 테마 선택, '이 폴더를 신뢰하느냐(trust)' 같은 질문이 한두 개 더 나올 수 있습니다. 테마는 아무거나, 신뢰 질문은 Yes를 고르면 됩니다.

잘 깔렸는지 확인하려면:

터미널 · 점검
claude --version
# 설치 상태를 종합 점검하려면
claude doctor

Codex (ChatGPT를 터미널에서)

터미널 · 설치
npm install -g @openai/codex
터미널 · 실행 / 로그인
codex

Codex도 처음 codex를 실행하면 비슷하게 ChatGPT 계정 로그인(브라우저 인증)을 거칩니다.

참고

이 외에도 Google Gemini CLI, Antigravity 등 여러 도구가 있습니다. 발표에서는 터미널에서 claude, codex, agy 처럼 한 단어만 입력해 실행하는 모습을 보여드렸습니다.

Windows 권한 오류로 설치가 안 될 때

명령 프롬프트(cmd)를 관리자 권한으로 실행(시작 메뉴에서 'cmd' 검색 → 우클릭 → '관리자 권한으로 실행')한 뒤 설치 명령을 다시 실행하세요. Mac에서 권한 오류가 나면 sudo 대신 nvm으로 Node를 설치하는 방법을 권장합니다.

4VS Code 설치

까만 터미널 하나로도 작업할 수 있지만, 파일 탐색기·편집기·터미널이 한 화면에 있는 VS Code를 쓰면 훨씬 편합니다.

  1. code.visualstudio.com에서 내 운영체제용 설치 파일 받기
  2. 설치 진행 Windows 설치 중 'PATH에 추가', 'Code로 열기' 메뉴 추가 항목은 체크해 두면 편합니다.
  3. (선택) 한글 메뉴를 원하면, VS Code 왼쪽 확장(Extensions) 아이콘 → Korean Language Pack 검색 후 설치
개발자만 쓰는 프로그램 아닌가요?

아닙니다. 연구·분석·문서 작업 등 '내 컴퓨터에서 파일을 다루는 모든 일'에 쓸 수 있습니다. 특히 검증용 코드(Python·R·Stata)를 만들고 돌려보기에 강점이 있습니다.

5작업 폴더 만들기

LLM에게 작업을 시키려면, 먼저 작업할 '폴더(프로젝트)'를 정해야 합니다. LLM은 그 폴더 안의 파일들을 보고 일합니다.

  1. 새 폴더를 하나 만듭니다(예: my-analysis).
  2. VS Code에서 File → Open Folder (Ctrl+K 다음 Ctrl+O) 로 그 폴더를 엽니다.
  3. "Do you trust the authors of the files in this folder?" 가 뜨면 Yes, I trust를 누릅니다.
Windows 폴더는 C 드라이브 말고 D 드라이브에 만드세요

작업을 하다 보면 데이터·설치 파일·결과물이 쌓여 용량이 빠르게 늘어납니다. 그래서 새 작업 폴더는 윈도우가 설치된 시스템 드라이브(C:)가 아니라, 여유 있는 다른 작업 드라이브(예: D:\work\my-analysis)에 만드는 것을 권장합니다. C 드라이브가 가득 차면 컴퓨터 전체가 느려지거나 멈출 수 있습니다. Mac은 보통 디스크가 하나라 그대로 두면 됩니다.

6VS Code 통합 터미널에서 실행

VS Code 안에는 터미널이 들어 있습니다. 별도 창을 띄울 필요 없이 여기서 바로 LLM을 실행합니다.

  1. 상단 메뉴 Terminal → New Terminal (Ctrl+` 백틱 키) 로 터미널을 엽니다.
  2. 터미널의 현재 위치가 지금 연 프로젝트 폴더인지 확인합니다(경로가 보입니다).
  3. 아래를 입력해 LLM을 실행합니다.
VS Code 터미널
> claude

이제 이 폴더가 작업 무대가 됩니다. 폴더 안의 파일을 읽히고, 새 파일을 만들게 하고, 코드를 돌릴 수 있습니다.

Windows VS Code 터미널은 cmd로 바꿔 두세요

VS Code에서 터미널을 열면 보통 PowerShell이 먼저 뜹니다. 그런데 PowerShell에서는 보안 정책 때문에 npm으로 설치한 명령(claude·codex 등)이 막혀 실행이 안 되는 경우가 있습니다. 그래서 기본 터미널을 cmd(명령 프롬프트)로 바꿔 두는 것을 권장합니다.

바꾸는 법: 터미널 패널 오른쪽 위 + 옆의 ∨(아래 화살표) → 'Select Default Profile'(기본 프로필 선택) → 'Command Prompt' 선택 → 그 다음 여는 터미널부터 cmd로 뜹니다. (지금 열린 PowerShell 터미널은 휴지통 아이콘으로 닫고 새로 열면 cmd가 됩니다.)

한 프로그램 안에서 여러 개

터미널은 여러 개를 동시에 띄울 수 있고(분할), 왼쪽 탐색기에서 파일을 보며 작업할 수 있습니다. 이게 까만 터미널 하나보다 편한 이유입니다.

7마크다운(.md) 파일 만들기

LLM에게 무엇을 시킬지, 말로 길게 설명하기보다 마크다운 파일로 정리해 주면 훨씬 잘 알아듣고, 다음에 또 쓸 수 있어 토큰도 아낍니다. 마크다운은 #, - 같은 간단한 기호로 구조를 표현하는 문서 형식입니다.

  1. VS Code 왼쪽 탐색기에서 새 파일 아이콘을 누르거나 Ctrl+N
  2. 파일명을 Requests.md 처럼 .md로 끝나게 저장(Ctrl+S)
  3. 아래처럼 작성합니다.
Requests.md · 마크다운 예시
# 분석 요청

## 목표
- 청년 임금에 영향을 주는 요인 분석

## 데이터
- KEEP 1차~13차 본조사 원자료

## 원하는 산출물
1. 기초 통계표
2. 회귀분석 결과
3. 시각화 그림

작성한 마크다운이 어떻게 보이는지 확인하려면 Ctrl+Shift+V(미리보기)를 누르세요.

8'@' 기호로 파일 읽히기

이제 핵심입니다. LLM 프롬프트에서 @ 기호를 입력하면 폴더 안 파일·폴더 목록이 떠서, 원하는 것을 골라 LLM에게 '읽혀' 줄 수 있습니다.

claude 프롬프트
> @Requests.md 이 요청대로 분석 계획을 세워줘

@를 치면 자동완성 목록이 나옵니다. 파일뿐 아니라 폴더도 통째로 참조할 수 있고, 여러 개를 한 번에 넣을 수도 있습니다.

여러 개 참조 예시
> @Requests.md @data/ 폴더의 자료로 @Work_inst.md 를 실행해줘
웹 화면과 가장 다른 점

웹(GUI)에서는 업로드할 수 있는 파일 수·용량이 제한됩니다. 터미널에서는 @로 내 컴퓨터의 원하는 파일과 폴더를 직접 가리켜 작업시킬 수 있습니다. 데이터 분석처럼 파일이 많은 일에 특히 강력합니다.

이제 배운 것을 모아, 실제 분석 한 바퀴를 돌려봅니다. 흐름은 데모와 동일합니다.

  1. 프로젝트 폴더 열기 · VS Code에서 분석할 폴더를 엽니다(5단계).

  4. 실행 · 터미널에서 claude 실행 후, 지시서를 읽힙니다.

"분석해줘"보다 "분석할 수 있는 파이썬(또는 R/Stata) 코드를 만들어줘"라고 시키면, 코드가 남아 검증·재현이 쉬워집니다. 결과만 받는 것보다 훨씬 믿을 수 있습니다.

10자주 겪는 문제 (해결법)

명령어를 못 찾는다 ('node'·'claude' is not recognized)

설치 직후 흔합니다. 터미널과 VS Code를 완전히 종료 후 재실행하세요. 그래도 안 되면 컴퓨터를 재부팅합니다.

npm 전역 설치에서 권한 오류

Windows 명령 프롬프트(cmd)를 관리자 권한으로 실행해 다시 설치. Mac sudo 남용 대신 nvm으로 Node 재설치를 권장.

로그인 브라우저가 안 열린다

터미널에 표시되는 인증 주소(URL)를 복사해 브라우저 주소창에 직접 붙여 넣어 로그인하세요.

터미널에서 한글이 깨진다

Windows 터미널을 UTF-8로 바꾸면 해결되는 경우가 많습니다.

명령 프롬프트(cmd) · UTF-8
chcp 65001

11꼭 기억하세요: 비용과 컨텍스트

  • 토큰은 곧 비용입니다. 불필요하게 길게 끌거나 같은 걸 반복시키면 비용·시간이 늡니다.
  • 컨텍스트 윈도우는 LLM이 한 번에 기억하는 작업 공간입니다. 한 세션이 너무 길어지면 넘쳐서 엉뚱한 답을 합니다. 작업 단위로 정리하고, 새 작업은 새 세션(/clear)으로 시작하세요.
  • 계획 검토·결과 검토는 사람의 몫입니다. LLM은 실행을 돕지만, 옳고 그름의 최종 판단은 연구자가 합니다.
  • 그래서 가장 중요한 것은 연구자의 배경지식입니다. 투입 변수·분석 방법·해석을 알아야 좋은 질문을 하고 좋은 결과를 가려낼 수 있습니다. 모르는 것은 LLM에게 묻고, 논문·저서로 확인하며 배워 가면 됩니다.
한 문장 요약

무작정 "해줘"가 아니라 요청 명확화 → 계획 → 검토 → 실행 → 검증의 리듬으로, 사람과 LLM이 역할을 나눠 일하는 것이 핵심입니다.
